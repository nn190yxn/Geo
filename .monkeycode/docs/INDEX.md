# 多品牌 GEO 管理平台项目文档

## 项目概述

本项目使用 npm workspaces 组织 React 前端、NestJS API、Prisma/PostgreSQL 数据层和共享类型，覆盖品牌资料、AI 回复监测、可见性指标、内容优化、发布准备、复测和自动化运营流程。
