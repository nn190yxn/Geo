# AI 自动化运营员实施计划

- [x] 1. 建立自动化任务包契约
  - [x] 1.1 在 shared-types 中新增 `AutomationPackage`、`AutomationStepSummary`、`AutomationConfirmation` 和 `PlatformRewriteVersion` 类型。
  - [x] 1.2 定义自动化状态、步骤 code、确认类型和确认动作枚举。
  - [x] 1.3 确保所有自动化结构包含 `brandId` 和可追溯关联 ID。
  - [x] 1.4 编写 shared-types 类型检查。

- [x] 2. 增加后端自动化模块
  - [x] 2.1 新建 `automation` module、controller、service 和 repository port。
  - [x] 2.2 实现 `AutomationOrchestratorService` 创建任务包和读取上下文。
  - [x] 2.3 实现自动化步骤状态推进和失败转移。
  - [x] 2.4 接入品牌访问校验和审计记录。

- [x] 3. 实现确认队列
  - [x] 3.1 新建 `ConfirmationQueueService`。
  - [x] 3.2 支持监测问题、分析判断、内容草稿、平台改写、发布建议和手动录入确认事项。
  - [x] 3.3 支持确认通过、用户编辑、重新生成和跳过。
  - [x] 3.4 确保必需确认事项阻塞下一步骤。
  - [x] 3.5 编写确认队列单元测试。

- [x] 4. 串联自动生成监测问题池和本轮精选问题
  - [x] 4.1 自动化任务包启动后调用现有监测主题和监测问题生成能力。
  - [x] 4.2 建立监测问题池，支持按品牌词、品类词、地域词、人群、痛点、课程、竞品、购买决策、内容缺口和复测目标持续扩展。
  - [x] 4.3 从监测问题池中默认筛选 5 到 6 个高价值本轮精选问题。
  - [x] 4.4 创建本轮精选问题确认事项。
  - [x] 4.5 用户确认后保存为监测计划。
  - [x] 4.6 新资料、监测结果、竞品变化、内容发布记录或复测结果进入系统后，生成下一轮候选问题。
  - [x] 4.7 覆盖追光小牛样例问题池和本轮精选问题测试。

- [x] 5. 串联自动监测执行
  - [x] 5.1 复用 `POST /test-plans/:planId/execute` 执行已确认监测计划。
  - [x] 5.2 将 API、浏览器和手动路径执行摘要写入自动化任务包。
  - [x] 5.3 浏览器异常时创建手动录入确认事项。
  - [x] 5.4 监测完成后触发回答分析步骤。
  - [x] 5.5 编写 API、浏览器异常和手动兜底路径测试。

- [x] 6. 串联自动分析和运营判断
  - [x] 6.1 复用现有回答分析和规则二次校验。
  - [x] 6.2 汇总推荐率、排名、卖点准确性、竞品压制、引用缺口和风险表达。
  - [x] 6.3 对风险表达和无法判断项创建确认事项。
  - [x] 6.4 用户确认后将判断写入内容生成上下文。
  - [x] 6.5 编写分析确认和风险表达测试。

- [x] 7. 串联可发布内容生成
  - [x] 7.1 基于分析结果创建内容生成任务。
  - [x] 7.2 复用 `ContentGenerationWorker` 生成内容版本。
  - [x] 7.3 确保生成结果包含标题、正文、引用依据、合规说明、建议发布平台和复测建议。
  - [x] 7.4 内容风险进入确认队列。
  - [x] 7.5 编写六类内容类型自动生成测试。

- [x] 8. 实现平台规则适配
  - [x] 8.1 新建 `PlatformRewriteService`。
  - [x] 8.2 支持知乎、百家号、小红书、公众号和官网 FAQ 改写规则。
  - [x] 8.3 保存平台改写版本和改写说明。
  - [x] 8.4 改写结果进入确认队列。
  - [x] 8.5 编写平台改写规则测试。

- [x] 9. 串联发布建议和复测建议
  - [x] 9.1 根据内容版本、平台改写版本和历史发布记录生成发布建议。
  - [x] 9.2 用户确认后创建发布记录或发布待办。
  - [x] 9.3 发布完成后生成复测计划建议。
  - [x] 9.4 复测结果回写自动化任务包。
  - [x] 9.5 编写发布建议和复测建议集成测试。

- [x] 10. 前端自动化运营体验
