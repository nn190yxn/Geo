# 多品牌 GEO 管理平台界面原型说明

## 1. 原型目标

本文件用于指导第一版后台原型设计和前端页面拆分，重点定义页面路由、导航结构、页面线框、组件字段和首版交付优先级。

第一版界面目标：

- 让用户能完成多品牌切换和品牌初始化
- 让用户能围绕优化单元和用户意图进行 GEO 监测
- 让用户能看到 AI 平台推荐、排名、引用和评价表现
- 让用户能从监测问题生成内容策略、内容草稿、发布记录和复测任务
- 让管理者能导出单品牌和多品牌报告

## 2. 全局布局

### 2.1 桌面端布局

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶部栏：当前品牌 / 全局搜索 / 通知 / 用户菜单                 │
├───────────────┬─────────────────────────────────────────────┤
│ 左侧导航       │ 主内容区                                     │
│               │                                             │

│               │                                             │
└───────────────┴─────────────────────────────────────────────┘
```

布局尺寸建议：

- 左侧导航宽度：240px
- 顶部栏高度：56px
- 主内容区最大宽度：自适应，最小内容宽度 1180px
- 主内容区内边距：24px
- 卡片圆角：8px
- 表格行高：52px

### 2.2 移动端策略

第一版后台以桌面端为主。移动端只保证可查看核心报表：

- 多品牌总览
- 单品牌 GEO 指标
- 任务状态
- 报告阅读

移动端隐藏复杂画布、内容编辑器和平台配置页面，提示用户使用桌面端操作。

## 6. 通用组件字段

### 6.1 KPI 指标卡

- `title`: 指标名称
- `tooltip`: 指标解释
- `value`: 主数值
- `unit`: 单位
- `delta`: 周期变化
- `deltaDirection`: 上升、下降、持平
- `badge`: 核心指标、需关注、监测中
- `status`: normal、warning、danger

### 6.2 趋势图卡片

- `title`: 图表标题
- `description`: 指标说明
- `timeRange`: 7 天、30 天、90 天
- `series`: 数据序列
- `legend`: 平台或品牌图例
- `tooltip`: 悬浮提示
- `emptyState`: 空状态

### 6.3 父子展开表格

- `parentRow`: 汇总对象
- `childRows`: 平台或 Prompt 明细
- `expandState`: 展开状态
- `metrics`: 指标列
- `rowActions`: 行内操作
- `bulkActions`: 批量操作

### 6.4 右侧详情抽屉

- `title`: 抽屉标题
- `summary`: 摘要信息
- `tabs`: 详情、记录、任务、日志
- `primaryAction`: 主操作
- `secondaryActions`: 次操作
